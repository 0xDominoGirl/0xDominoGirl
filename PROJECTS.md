## Onchain data and visualization

### [MegaETH Dual Block Production](https://github.com/0xDominoGirl/MEGAETH-DUAL-BLOCK-PRODUCTION)

A real-time visualizer of MegaETH mini blocks and EVM blocks, with transaction inspection and Blockscout links.

### [MegaETH Contract Deployment Heatmap](https://github.com/0xDominoGirl/megaeth-heatmap)

A heatmap of contract deployment activity, using a JSON snapshot of Dune query results. Explore deployment counts, unique deployers, and contract addresses across time buckets.

### [MegaETH Transaction Count Treemap](https://github.com/0xDominoGirl/megaeth-treemap)

A treemap of transaction counts across tracked MegaETH projects. A refresh script collects contract counters from Blockscout, aggregates them per project, and saves a snapshot for the browser to display.

[Open the treemap ↗](https://0xdominogirl.github.io/megaeth-treemap/)
